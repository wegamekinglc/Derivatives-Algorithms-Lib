reuse the accepted native planners, immutable storage and pullbacks. No second

prepare all owning outputs before publishing them. External direct absence has
an explicit flag and checked getter because the repository rejects null output
handles. Getters only copy retained passive values.

The old parser predicates/messages are preserved when shared. Fresh numeric
cells construct their variant alternative directly. Private numeric formatting
retains a separate local function to preserve the old small getter's compiled
layout. History headers construct their final string alternative directly.
Exact typed-cell/double-bit identity and affected-entry performance pass.

production has no new test-fixture dependency.
