## D1: same finite inputs, no IID assumption

The accepted scalar theorem provides E < 9.006864425e-9 on
`u=RN(k/d)`, k=1..d-1, d=4294967088, relative to PhiInv(u). The input is the
exact decimal rational upper bound; it is not the original 5e-13 diagnostic.
Scalar source SHA256 remains
`07cedff146fd4f897e0dc95329ff6082a70345895a4caf6ce1faa465b39c69e1`.
The theorem remains restricted to its accepted IEEE, FMA/contraction and bound
Linux libm/runtime assumptions. D1 does not independently extend that theorem
to a caller or absorb floating cashflow-pipeline error.

Let M=25/4. Mills gives `Q(M)<phi(M)/M<1/d-2^-54`, so exact-grid and rounded-grid
ideal quantiles are inside [-M,M]. For one term set L=||ell||_1, G=||g||_1,
and H=exp(k+M L). If every coordinate moves by at most E, outward majorants are

```text
delta_value <= |c| H expm1(E L)
delta_native <= H [(|d|+|c| M G) expm1(E L)
                         + |c| E G exp(E L)]
max_value <= |c| exp(k+(M+E)L)
max_native <= exp(k+(M+E)L) [|d|+|c|(M+E)G].
```

This follows by subtracting the two exponentials, bounding |ell.delta z| by
E L, and separating the extra g.delta z term. It is uniform over every finite
input vector in this box, so it holds for any same-weight sample mean without
an IID premise. Signed sums use the sum of absolute error majorants. Every
annuity term is negative. Thus
`m=sum_A |c| exp(k-(M+E)L)>0` bounds the absolute denominator for both paths,
every same-weight mean, and the segment joining them.

For coefficient mean differences ea,eb,eda,edb and common maxima B,DA,DB,
the quotient `r=-b/a` and its derivative satisfy

```text
delta_r <= eb/m + B ea/m^2
delta_r_native <= edb/m + DB ea/m^2
                   + (eb DA+B eda)/m^2 + 2 B DA ea/m^3.
```

This is the quotient of coefficient means, never mean(pathwise quotient).
All absolute annuity lower bounds are positive: conservatively >32.3210,
37.1028 and 38.3098 for D30/55/80. The worst finite-input majorants are useful
controls but not uniformly budget-small. For both fits:

## D2: explicitly conditional independent-grid law

Here, and only here, every numerator is assumed independent and uniform on
1..d-1. A fixed-seed MRG trace does not prove this joint law. This is a
conditional mathematical expectation theorem, including its native derivatives.

Set h=1/d, C=d/(d-1), t=PhiInv(1-h), and m0(a)=exp(a^2/2). The code brackets
t by 160 outward bisections, verifying Q(left)>h>Q(right); it does not use
an ordinary approximate inverse as an endpoint. For f(u)=exp(a PhiInv(u)),
the monotone left/right sums on [0,1-h] and [h,1] enclose h times the finite
interior sum. The two missing tails give the conservative normalized bound

```text
r0 = (C-1) + C Q(t-|a|).
```

This bound includes normalization and the larger tilted tail, for either sign
of a. It is conservative at a=0. For the weighted first moment use
f(z)=z exp(a z) on [-t,t]. Its only possible stationary point is -1/a.
If |a|t<=1, it is monotone; otherwise the sum of absolute increments through
-1/a bounds its variation, even if the stationary point lies outside the
interval. Interval endpoint arithmetic bounds every increment. With TV this
variation bound and endpoints=(|f(-t)|+|f(t)|)/2, trapezoid comparison gives

```text
tail1 = -a Q(t+a)+phi(t+a)+a Q(t-a)+phi(t-a)
r1 = (C-1)|a| + C [h(TV+endpoints)/m0(a) + tail1].
```

The two exact tail integrals are, after division by m0(a),
`Q(t-a)` and `Q(t+a)` for zeroth moments, and
`a Q(t-a)+phi(t-a)` and `phi(t+a)-a Q(t+a)` for absolute first moments.
No typical-payoff-times-tail-probability approximation is used.

Rounded uniform input is separate from the scalar implementation error:
`E_U <= 2^-54/phi(M) < 4.224587095e-8`. The Mills support proof and the inverse
CDF derivative imply this bound. With e=E+E_U and v=expm1(|a|e), augment

```text
r0 <- r0+(1+r0)v
r1 <- r1+(1+r0)[M v+e exp(|a|e)].
```

This couples exact-grid quantiles, rounded uniforms and actual scalar outputs.
The second line follows by expanding `(z+delta)exp(a(z+delta))-z exp(a z)`
and bounding |z|<=M. Neither error term is silently deleted.

Under the stated independent-coordinate law let P=product_i(1+r0_i).
The normalized product-moment error is at most P-1. For the ith first moment
and all other zeroth moments its normalized error is bounded by
`r1_i product_(j!=i)(1+r0_j)+|ell_i|[product_(j!=i)(1+r0_j)-1]`.
The derivative term uses this bound weighted by |c g_i|, plus |d|(P-1).
Signed Gaussian centers are calculated independently as

```text
mean_term = c exp(k+sum ell_i^2/2)
mean_native_term = exp(k+sum ell_i^2/2) [d+c sum g_i ell_i].
```

Summing signed centers and absolute error boxes gives a,b,da,db and
ea,eb,eda,edb. With q=|a|-ea>0, for ratios of these expectations:

```text
delta_r <= (eb+|b/a|ea)/q
delta_r_native <= edb/q + |db|ea/(|a|q)
  + [eb(|da|+eda)+|b|eda]/q^2
  + |b da|ea(2|a|+ea)/(a^2 q^2).
```

Every q is positive, conservatively >54.7014, 108.6859 and 162.7988. Both fits
have the following upward summaries; canonical binary endpoints are definitive:
