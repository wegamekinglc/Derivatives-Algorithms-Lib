# Native diagnostic design critique

Verdict: Proceed with caveats.

No blocking design issue remains in the controlling specification. Acceptance
must distinguish cached report storage from the caller-owned copy: moving a
vector out of the event would escape its allocator account. Test report admission
before output publication and destruction after close/restore under a parent
buffer budget, rather than checking only numeric values.

Keep the optional surface in a new header and share reverse logic by cache type.
Template extraction can change compiled ordinary solve functions despite equal
layouts; executable identity or scoped paired measurements must establish
ordinary-path performance acceptance. Numeric diagnostic costs and native graph
assembly/reverse costs require separate observations.

The inverse-range policy is narrower than ordinary RHS solvability. Reproduce
that distinction and recording recovery. Passive diagnostic values make no claim
of condition-number differentiation or second-order support. Structured matrix
coordinates remain a following deliverable.
