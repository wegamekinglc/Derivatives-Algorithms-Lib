## 阻断项

### B1：默认预算将常用请求及第一轮空间收敛挡在预检阶段

证据位置：API 第 5 节 `:136-149`、`:162-187`，第 7 节 `:289-306`，第 10 节 `:473-475`。
这里及下文的 API 行号均指上述原稿。

按记录规定的均匀 spot 网格，central 生成元在第 `i` 行的对角为
`L_ii = -(sigma^2*i^2+r)`。CN 要求显式对角非负，因此

```text
dt <= 1 / ((1-theta)*(sigma^2*(N-2)^2+r))
```

取 `S=K=100`、一年、`r=0.05,q=0`、单段 carry、American，其他设置默认。
最右内部行满足 central 的非负邻系数要求；低端的 upwind 不改变以下约束。
基础 `dt=1/500`；前两个基础步各换成两个隐式半步，其余 498 步按二分细化。

| N / sigma | CN 最大 dt | 二分因子 | 实际子步 | 区域预检记录上界 | 仅四个 int 字段的下界 |
|---|---:|---:|---:|---:|---:|
| 401 / 0.20 | 0.000314066 | 8 | 3,988 | 801,588 | 12.23 MiB |
| 401 / 0.50 | 0.0000502509 | 64 | 31,876 | 6,407,076 | **97.76 MiB** |
| 801 / 0.20 | 0.0000783205 | 32 | 15,940 | 6,391,940 | **97.53 MiB** |

最后一列只按每条区域的 `time_index,region_index,first_node,last_node` 四个
32-bit int 计 16 字节，未计两个 bool、结构 padding、时间网格、逐步诊断、层记录或容器余量。
这已经超过 64 MiB；四个 int 是当前 Linux 基线下的保守下界，不是在猜未实现结构的精确 `sizeof`。
这些配置未超过 100,000 子步；每步一次求解只约 1,272 万 work units，也未触及一亿计数。

这是**最坏存储预检导致的确定性拒绝**，不是声称 vanilla put 实际产生了几百万个区域。
实际通常只有少量区域，但原稿明确要求先按每层 `ceil(N/2)` 覆盖预检，不能用实际稀疏性放行。
该策略在 CN 的 `steps=O(N^2)` 下将区域存储上界推至 `O(N^3)`，使普通参数和空间收敛受默认预算限制。

**实施前处理：**在原 API 记录明确选定一种一致的政策，并写入上述两个拒绝案例及对应可执行配置：

1. 优先考虑默认 `theta=1`，保留 CN 为显式选择并说明其预算；全层区域及事前上界不变。
   这把上述无额外事件的默认计划降至 500 步，代价是时间一阶，仍须独立时间收敛。
2. 或保留默认 CN，但调整默认预算并给出代表参数范围、空间加密所需的显式预算和可接受的工作量。
   不能把 128 MiB 当作统一解决方案，其他诊断和更大网格仍会增长。
3. 或修订为受总预算约束的实际区域容量增长/可选诊断策略；这会改变预检、途中失败或全层输出契约，
   须明确状态和失败结果，不能在实现中悄悄省略区域、降低单调性或把分配移出计账。

解除条件是**固定一项政策和可复核的计划/字节算式**；本阶段不要求先实现求解器或重跑构建。
不要求为所有有限输入保证成功，但不能把这些常用案例仅留作未决默认风险。

## 重要关注项：实现时定向验证

### S1：固定 penalty 的偏差与浮点误差必须分别验证，增加迭代不能消除 penalty 偏差

API `:214-249` 的原始 LCP 定义、行归一化单位、独立线性误差和失败价格隔离是正确的方向。
`max(abs(min(gap,w)))` 检查的是离散互补条件；不能只看 active set 不变、penalized residual 或 iterate change。

用独立标量接触行即可检验准入是否真实：`g=20,r=q=0.1,sigma=0,dt=0.002,theta=0.5`，
前层值为 g。此时 `A=1.0001,b=0.9999*g`，penalty 精确解的障碍缺口是

```text
delta = dt*r*g / ((1+theta*dt*r)*(1+penalty_factor))
```

`penalty=1` 得 `delta=0.00199980002`，即使 penalized 线性残差和第二次改变量为 0，
也远大于 `C=100` 时的 `epsilon=2e-8`，应拒绝并最终报告 `LCP_RESIDUAL_LIMIT`。
`penalty=1e8` 对同一行的理论缺口约 `4e-11`；这支持保留默认值做实测，**不证明**所有网格、负 carry 或混合 active/inactive 行均可达标。

对混合行，`Â+lambda*D` 的对角尺度可相差约 `1+lambda`；单个 backward error 小不推出 forward error 小。
默认 `1e8` 暂无证据必须换掉，也不能因上限允许 `1e12` 就认证其可达精度。
建议实现时考虑用相对 payoff 的修正变量、合适的求解行缩放，原始 LCP 残差仍在固定的未加 penalty 数据上独立重算。
固定 active set 后原始残差仍超限，应按既定失败语义结束；不得加迭代掩盖偏差或预算外倍增 penalty。

[Forsyth–Vetzal 原论文](https://cs.uwaterloo.ca/~paforsyt/con7.pdf) 第 4.1 节、定理 4.1 和表 8.2
分别讨论 penalty 偏差的条件及机器精度限制；它的离散缩放与本 API 不同，不能直接据其因子或收敛表认证本默认值。

原稿 `:237-249` 另须澄清：准入只限制“最后一次” backward error，还是每次实际求解均须通过。
建议每次均检查、任一次超限即失败，并保留逐步最大值；避免摘要超限但状态成功的歧义。

### S2：单调 stencil、负利率、零波动率有可实施路径，不能直接套现有 theta

central 邻系数为 `a-=0.5*sigma^2*i^2-0.5*(r-q)*i`、
`a+=0.5*sigma^2*i^2+0.5*(r-q)*i`。退化时应按生成元邻系数选择方向：
`r-q>0` 用向右差分，`r-q<0` 用向左差分，才能得到非负邻系数；不能按 forward advection 的直觉反选。
`sigma=0,r=q` 是完全对角的合法退化，不得通过除以 sigma、加 vol floor 或 CRR 概率 clamp 处理。

建议固定严格行对角占优这一充分条件：邻系数非负、`1+theta*dt*r>0`，并验证正主元；
CN 还需 `1-(1-theta)*dt*(a-+a++r)>=0`。负 r 时必要细分，隐式也不能豁免。
这些条件只给离散单调性和安全求解，不等同连续价格精度；near-zero 的单边误差可能是一阶。

现有 `dal-cpp/dal/math/pde/thetascheme.cpp:166-204` 直接构造 central 算子并分解，
没有该单调性策略；`test_thetascheme.cpp:121-148` 只证明 target/source 边界的 theta 权重，
`:201-214` 是 European call 对照。新策略留在独立路径较小，勿无意改变旧 European/AAD 数值。
首轮保留一个“首个粗步不满足、二分后满足”的负 r 案例，并检查事件未移位、没有新增 Bermudan 投影、
实际步骤和预算包含全部细分。半步端点若不可表示也必须有界失败，不能无限二分。

### S3：边界包络合理，但有限 upper 的误差与事件顺序要有能击穿错误的对照

API `:197-212` 对 `S=0` 的未来最优贴现边界成立，负利率下不能复用 test helper 的“下一个行权日”政策。
有限 upper 上的确定性包络是近似；通过 LCP、线性残差或单次 CRR 对价都不能单独证明截断足够小。
不建议现在引入自动 upper 选取，按原稿固定局部 `ΔS` 扩域并记录价格/接触括区即可。

固定一个独立驻点对照：在边界 `s=4K`、`r=-0.2,q=-0.1,T=10,sigma=0` 的 American call，
`F(e)=4K*exp(0.1e)-K*exp(0.2e)` 在 `e=log(2)/0.1` 取最大 `4K`，两端均更小。
只扫描段端点或按日采样都不能冒充这个解析最大值。需另覆盖 `r=q`、零 r/q、
驻点恰在端点、无有效驻点；相消时用稳定计算，检查中间量和最终值有限。
`S=0` 的边界通过返回网格/估值层核验，无须放宽 `spot>0`。

Bermudan 的 continuation 使用严格未来的目标边界、投影后才包含当日的顺序已写清，
实现时仍须沿用 source 的已投影边界与 target 的未投影 continuation 边界，不能将两者覆盖成同一个值。

### S4：验收矩阵方向正确，需把少数具体 oracle 和“缺失行为必失败”条件固定下来

API `:444-486` 已区分解析/CRR、残差、收敛和跨绑定，且没有将同源 helper 或 LSMC 当唯一 oracle。
但只列类别和暂定容差还不足以控制实现：European call 等价、非严格单调性和绑定相等，
都可能由“所有请求只返回 European”通过；单次空间/时间差也可能落在抵消或相位巧合上。
保留矩阵，补下面这个小集合即可，不需要完整参数笛卡尔积：

| 对照 | 固定输入与断言 | 必须击穿的错误 |
|---|---|---|
| 提前行权与精确日期 | `d0=2026-10-18,d1=2027-03-04,dT=2027-10-18`，相差 137/365 天；`S=80,K=100,sigma=0,r=q=0.1`。American 价格 20，Bermudan `[d1,dT]` 为 `20*exp(-0.1*137/365)`，仅到期为 `20*exp(-0.1)` | 漏投影、误将今日可行权、把不规则事件 snap 到普通时间层 |
| carry 顺序 | 同日期/spot/strike，`r=q=-0.2` 至 d1，其后 `r=q=0.2`，sigma=0；American 和上述 Bermudan 均在 d1 最优，值为 `20*exp(0.2*137/365)` | 只用整期限平均 carry、段归属或符号错误 |
| stochastic 障碍 | 常 carry 的正利率 put、带 yield call，独立 CRR 多个树深及奇偶包络；至少一例的独立早行权溢价大于合并误差预算的 5 倍 | 障碍缺失而 European 仍通过；单一树深偶然吻合 |
| 原始 LCP | S1 标量行及小型、独立组装的三对角 LCP，枚举少量 active sets 作参照；低 penalty 必失败，高 penalty 同时验证实际残差 | 用 penalized residual 代替原始残差、只比较两次迭代、诊断硬填 0 |
| 分离收敛/截断 | 至少三档空间、三档实际时间分辨率和两次扩域，分别固定其他误差源；空间档含 strike 在节点和节点间 | 两档相位巧合、上下界/时空误差抵消、只检查残差 |

前两个确定性案例可把独立价格门槛固定为 `1e-6*C`，使用足够细时间令时间误差低于该门槛；
例如 theta=1 时基础步至少 5,000，再独立确认时间误差。这里无 diffusion/drift，ITM payoff 为仿射，
不需靠细空间网格获得日期敏感度；错一天约产生 0.005 的价格差，明显超过该门槛。
它们不能替代有正波动率的 CRR 案例，也不能把确定性公式直接当任意 near-zero sigma 的精确解。
正的 near-zero 测例需选独立解析 European 对照或预先证明的确定性近似误差界，不能强行造不可用树。

CRR 的 oracle 自身应先收敛到比 `1e-4*C` 更紧的已记录带宽，才把剩余预算留给 PDE；
准确日期可用日步长的整数细分对齐。分段 carry 的树必须明确每段概率和事件归属，不能复用 PDE 边界/投影。
Greek/AAD 或多个语言结果一致均不替代这个参照。

嵌套日程的“同一时间网格”断言需给出可构造方式：把各日程并集作为各请求共同的等值 carry 分段，
令 theta=1（或关闭 Rannacher），使锚点和实际计划相同，再只改变投影标签；不要把不同自动时间计划的价差当作金融单调性反例。
American 的原始残差允许有限 penalty 缺口，不宜用零容差比较其与投影式 Bermudan 的下界。

工作区 `256*N` 的包络也与最多 24 个 double 加 16 个 32-bit int 数组相符；实际布局仍须实现时证明。

API `:320-328` 的七行加密算式逐行复核一致：固定 M=500 的 N=401→801→1601，
以及固定 N=401 的 M=500→1000→2000、固定 N=801 的 M=500→750→1000，全部同时在四项默认上限内。
这些行的逐项最大值为 payload **13642672 bytes**、workspace **446080 bytes**、
子步 **2000**、U100 **79950000**；最大值来自不同行，不表示它们是一组额外联合配置。
这关闭了“改默认后把冲突移到另一上限”的问题，但不证明表中时间/空间分辨率已足够定价。

显式 CN 的二分与包络亦独立复核一致：

| CN 案例 | M | Payload bytes | Workspace bytes | U100 |
|---|---:|---:|---:|---:|
| N=401、sigma=50% | 31876 | 217277488 | 2146944 | 1271852400 |
| N=801、sigma=20% | 15940 | 210680112 | 1229440 | 1273606000 |

API `:306-312` 在只选 CN 时仍按默认 64 MiB 预检拒绝；显式提升 payload 和 work 至上述值后，
两组计划通过容量上界核对，workspace 和子步可继续使用默认值。所有数值也可表示为 32-bit size_t，
不存在示例本身的窄化溢出。U100 是最多尝试次数的包络，不是 penalty 收敛保证。

API `:253-263,335-339` 的阶段划分一致：payload/workspace/子步预算不足在大分配及 rollback 前抛异常，
不按实际稀疏区域豁免；work 不强制预留 U100，按实际每次线性求解核算，耗尽返回 `WORK_LIMIT` 且没有价格。
因此只提高 CN 的内存预算不必然失败，也不承诺成功；是否耗尽 work 取决于实际尝试次数。
预算恰等 P_plan/W_plan 可通过预检、少 1 byte 拒绝，M-1 步上限拒绝的定向用例已列明。

### 重要关注项（继续随实现验证）

- 默认改为一阶时间格式不会自动满足原价格误差目标。空间收敛仍要固定充分细时间，
  时间收敛仍要固定充分细空间/上界；七行可用预算不是两轴误差已被隔离的证据。
  若需要超出这些行的分辨率，应显式核算预算，不放宽价格门槛。
- P_plan/W_plan 是新规定的存储上限包络，尚无实际结构或运行峰值证据。
  实现须证明 sizeof、optional/padding、所有 capacity、预留区域表和同时活跃的临时数组均符合包络，
  并区分 planned 与 actual 计数；不得把未计账的 full-layer 拷贝留在包络外。
- fully implicit 的大扩散对角不会限制上述步数，但仍可能影响条件数、归一化 penalty 的浮点精度及迭代数。
  原始 LCP/线性误差、penalty 可达精度、负 rate 的必要细分及首轮 S1–S4 的定向验收继续有效。
