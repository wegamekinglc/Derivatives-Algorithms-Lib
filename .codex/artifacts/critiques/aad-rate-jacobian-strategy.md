# Strategy design critique

Verdict: Proceed with caveats.

The direct dense planner is a useful small change: generic row coloring adds
quadratic conflict work to a matrix whose coloring is known. Its budget gate
must precede Cartesian metadata allocation, including when one axis is zero.
Metadata equality with generic planning and independent matrix recovery provide
the behavioral oracle; tests must not assert wall-clock thresholds.

The larger grouped deposit workload can establish a real financial compression
benefit, but cannot establish a universal threshold for seven instrument and
four curve families. Report it as a scoped observation. The accepted layered
case remains a required adverse boundary, and the two-shared-curve shape tests
an input-poor/output-rich request without pretending native forward exists.

Keep cold capture/coloring separate from reusable execution. A cached plan still
recaptures current identity; removing that check to win a benchmark is blocked.
Numeric point changes require fresh recording and do not invalidate conservative
structural support merely because an entry becomes zero.

The first full-cost study establishes a dense advantage on all declared shapes.
Keep that default. The added opt-in cached-plan overload needs current requested
axes, a single identity capture, fresh recording, explicit dense fallback on
mismatch and actual executed direction counts. Do not catch arbitrary pricing
exceptions as an invalidation signal. Tight compressed-only budgets can reject
a stale plan's larger dense fallback; test this before publication.

No blocking issue in the revised design. Published guidance must distinguish
safe fallback from cost-based automatic selection, and disclose the measured
compression overhead and unsupported native forward capability.
