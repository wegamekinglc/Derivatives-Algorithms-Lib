# Currency Curves

[Cross-currency pricing and calibration](pricing-calibration.md) covers FX-forward
conventions, fixed and resettable notionals, market-fixing snapshots, staged
basis calibration, and the joint domestic/foreign/basis solve. Its examples use
the C++ public facade. The [yield-curve Jacobian guide](../yield-curves/jacobian-risk.md)
explains the corresponding matrix blocks and quote-risk transform.

For binding-specific calls, see [Python](../python/README.md) and
[Excel](../excel/README.md).
