RateFraTrade_New (in Excel: RATEFRATRADE.NEW)

Inputs:

NameTypeOptional?
instrumentIdstringTrade identifier
tradeDatedateThe trade date
startdateThe start date
maturitydateThe maturity date
currencystringTrade currency code (the actual PV denomination)
notionalnumberPositive notional
contractRatenumberContract rate
receiveFloatingbooleanTrue to receive the floating leg

fixingHourintegerFixing publication hour (0-23)
fixingMinuteintegerFixing publication minute (0-59)
forecastComponentKeystringMarket component key of the forecast curve
discountComponentKeystringMarket component key of the discount curve

Outputs:
