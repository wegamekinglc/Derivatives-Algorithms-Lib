CurveBlock_New (in Excel: CURVEBLOCK.NEW)

Build a curve block with explicit discount and projection curves

Inputs:

NameTypeOptional?
namestringA name for the curve block
ccystringCurrency code (e.g. "USD")
discountshandle of type StorableCalibrationDiscountCurvesCollateral-keyed discount curve bindings
forwardshandle of type StorableCalibrationForwardCurvesTenor-keyed projection curve bindings
liborBasisstringyesLibor day basis name (default "ACT_365F")

Outputs:

NameType
blockhandle of type StorableCurveBlockThe curve block
