DiscountZeroRate_New (in Excel: DISCOUNTZERORATE.NEW)

Build a discount curve from continuously compounded zero rates

Inputs:

NameTypeOptional?
namestringA name for the curve
ccystringCurrency code (e.g. "USD")
anchorDatedateAnchor date for the zero rates
nodeDatesvector of datesFuture node dates for the curve
zeroRatesvector of numbersContinuously compounded zero rates at each node date

Outputs:

NameType
