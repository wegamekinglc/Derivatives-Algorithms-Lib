CalibrateXccyMarket_New (in Excel: DA.CALIBRATEXCCYMARKET)

Calibrate a cross-currency basis market from instruments and settings

Inputs:

NameTypeOptional?
todaydateThe valuation/trade date
domesticCcystringDomestic currency code (e.g. "USD")
foreignCcystringForeign currency code (e.g. "EUR")
domesticBlockhandle of type StorableCurveBlockThe pre-calibrated domestic curve block
foreignBlockhandle of type StorableCurveBlockThe pre-calibrated foreign curve block
instrumentsvector of handlesArray of cross-currency swap instrument handles (created with DA.CROSS.CURRENCY.SWAP.NEW)
knotDatesvector of datesKnot dates for the basis curve
settingsmatrix of cellsyesOptional settings as a two-column range. Supported keys: fxSpot (number), fxForwardCollateral (string), smoothingWeight (number), tolerance (number), fitTolerance (number), initialGuess (number), maxEvaluations (integer), maxRestarts (integer), solveMode (string: EXACT|APPROXIMATE)
formatstringyes(Excel only) Desired screen layout of outputs; see QR.FORMAT.

Outputs:

NameType
basisCurvehandle of type StorableDiscountCurveThe calibrated basis discount curve
maxAbsResidualnumberMaximum absolute residual
rmsResidualnumberRoot-mean-square residual
