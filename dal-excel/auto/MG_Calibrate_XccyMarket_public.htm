Calibrate_XccyMarket (in Excel: CALIBRATE.XCCYMARKET)

Calibrate a cross-currency basis market from instruments and settings. Returns a result handle bundling the basis curve and the fit diagnostics.

Inputs:

NameTypeOptional?
todaydateThe valuation/trade date
domesticCcystringDomestic currency code (e.g. "USD")
foreignCcystringForeign currency code (e.g. "EUR")
domesticBlockhandle of type StorableCurveBlockThe pre-calibrated domestic curve block
foreignBlockhandle of type StorableCurveBlockThe pre-calibrated foreign curve block
instrumentsvector of handlesArray of cross-currency swap instrument handles (created with CROSSCURRENCYSWAP.NEW)
knotDatesvector of datesKnot dates for the basis curve
settingsmatrix of cellsyesOptional two-column (key,value) settings. Keys: fxSpot, fxForwardCollateral, smoothingWeight, tolerance, fitTolerance, initialGuess, maxEvaluations, maxRestarts, solveMode (EXACT|APPROXIMATE)

Outputs:

NameType
resulthandle of type StorableCrossCurrencyCalibrationResultThe cross-currency calibration result (basis curve + diagnostics)
