Node sensitivities of a trade batch as a long-form spill

Inputs:

NameTypeOptional?
tradesvector of handlesRate trade definition handles (created with the RATExxxTRADE.NEW builders)
componentKeysvector of stringsOne shared component key list applied to every trade

Outputs:

NameType
spillmatrix of cellsLong-form rows of trade, component, reason, pv, node, value: one row per node of each eligible (trade, component) cell, one reason row per failed cell. Node labels pair the parameter date with its free-parameter component.
