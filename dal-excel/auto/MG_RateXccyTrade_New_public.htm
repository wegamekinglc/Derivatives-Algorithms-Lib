RateXccyTrade_New (in Excel: RATEXCCYTRADE.NEW)

Create a cross-currency swap rate trade for node-sensitivity pricing

Inputs:

NameTypeOptional?
instrumentIdstringTrade identifier
tradeDatedateThe trade date
startdateThe start date
maturitydateThe maturity date
positionCountnumberPositive position count
contractSpreadnumberContract spread on the spread leg
spreadOnForeignLegbooleanTrue when the spread rides the foreign leg (must match the config convention)
receiveNonSpreadbooleanTrue to receive the non-spread leg
confighandle of type StorableCrossCurrencySwapConfigThe cross-currency swap config (domestic currency of the pair is the actual PV denomination)

Outputs:

NameType
tradehandle of type StorableRateTradeDefinitionThe cross-currency swap trade definition
