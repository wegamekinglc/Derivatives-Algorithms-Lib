CalibrationResult_Get (in Excel: CALIBRATIONRESULT.GET)

Extract a diagnostic attribute from a curve calibration result. Use CALIBRATIONRESULT.GET.CURVE for the curve itself.

Inputs:

NameTypeOptional?
resulthandle of type StorableCurveCalibrationResultThe calibration result handle (from CALIBRATE.SINGLECURVE)
attributestringAttribute name: marketRates, modelRates, residuals, maxAbsResidual, rmsResidual

Outputs:

NameType
valuematrix of cellsThe requested diagnostic. Rate vectors (marketRates/modelRates/residuals) return as an Nx1 column; scalar stats (maxAbsResidual/rmsResidual) return as 1x1.
