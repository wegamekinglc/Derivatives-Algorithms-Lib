# Native AAD Risk Worksheet Examples

Load the native DAL XLL and use a separate sheet for each example. Enter script
text as literal cell contents, not Excel formulas. Dates below are Excel
`DATE(year, month, day)` formulas. Calls use comma separators; regional Excel
settings may require semicolons. The [example catalog](../../docs/examples.md)
links the matching C++/Python programs and numerical definitions.

## Segmented Monte Carlo spot curvature

Enter these inputs:

| Cells | Contents, in range order                 |
|-------|------------------------------------------|
| A5:A6 | `SCALE`; `=DATE(2027,10,10)`             |
| B5:B6 | Text `'2`; `pay PAYS SCALE * spot() ^ 2` |
| D5:E5 | `evaluation_date`; `=DATE(2026,10,10)`   |
| H5:H9 | `100`; `0.2`; `0.03`; `0.01`; `2`        |
| J5:N5 | `1`; `0`; `0`; `0`; `0`                  |
| J6    | `0.1`                                    |

Enter the handle and result formulas in this order:

```text
B8  =PRODUCT.NEW("quadratic",A5:A6,B5:B6)
B9  =SCRIPTVALUATIONSETTINGS.NEW("valuation",D5:E5)
B10 =BLACKSCHOLESMONTECARLOPLAN.NEW("plan",B8,B9)
B11 =BUMPOVERAADREQUEST.NEW("spot",J5:N5,J6)
B12 =BLACKSCHOLESMONTECARLOCURVATURERESULT.NEW("curvature",B10,H5:H9,33,B11)
B13 =BLACKSCHOLESMONTECARLOCURVATURERESULT.GET.BASE(B12)
B14 =BLACKSCHOLESMONTECARLORESULT.GET.VALUE(B13)
J10 =BLACKSCHOLESMONTECARLORESULT.GET.GRADIENT(B13)
B15 =BLACKSCHOLESMONTECARLOCURVATURERESULT.GET.HESSIANPRODUCTS(B12)
B16 =ABS(B15-2*B14/H5^2)
```

Leave spill ranges empty: J10 returns five gradient rows and B15 returns one
row with five HVP columns. `H5:H9` is the complete raw point: spot, volatility,
rate, dividend yield and SCALE. The unit spot direction and outer step 0.1
select spot Gamma in B15; later columns are its mixed products. B16 should be
near floating-point zero because each common-path payoff is quadratic in initial
spot. It does not measure Monte Carlo pricing error. Omitted execution settings
use native defaults; the base handle is reused without another valuation.

## Frozen and retrained LSMC curvature

On another sheet, enter:

| Cells   | Contents, in range order                      |
|---------|-----------------------------------------------|
| A5:A6   | `=DATE(2027,4,10)`; `=DATE(2027,10,10)`       |
| B5:B6   | `EXERCISE MAX(100 - spot(), 0)` in both cells |
| D5:E5   | `evaluation_date`; `=DATE(2026,10,10)`        |
| D8:E8   | `enable_aad`; Excel Boolean `TRUE`            |
| D9:E9   | `compiled`; Excel Boolean `TRUE`              |
| D10:E10 | `lsmc_training_paths`; `256`                  |
| D11:E11 | `lsmc_policy_risk_mode`; `Frozen`             |
| D12:E12 | `lsmc_policy_bump_relative`; `0.002`          |
| H5:H8   | `100`; `0.2`; `0.05`; `0`                     |
| J5:M5   | `1`; `0`; `0`; `0`                            |
| J6      | `0.1`                                         |

```text
B8  =PRODUCT.NEW("bermudan",A5:A6,B5:B6)
B9  =SCRIPTVALUATIONSETTINGS.NEW("valuation",D5:E5)
B10 =MONTECARLOSETTINGS.NEW("simulation",D8:E12)
B11 =BLACKSCHOLESLSMCPLAN.NEW("plan",B8,B9,B10)
B12 =BUMPOVERAADREQUEST.NEW("spot",J5:M5,J6)
B13 =BLACKSCHOLESLSMCCURVATURERESULT.NEW("curvature",B11,H5:H8,129,B12)
B14 =BLACKSCHOLESLSMCCURVATURERESULT.GET.VALUE(B13)
B15 =BLACKSCHOLESLSMCCURVATURERESULT.GET.GRADIENT(B13)
D15 =BLACKSCHOLESLSMCCURVATURERESULT.GET.HESSIANPRODUCTS(B13)
J10 =BLACKSCHOLESLSMCCURVATURERESULT.GET.EXECUTION(B13)
```

Leave B15:B18, D15:G15 and the execution spill starting J10 empty. D15 is the
spot directional-curvature estimate in raw units. The retained execution should
identify three gradient evaluations and the Frozen policy method.

Change E11 to `RetrainedBump` and recalculate the simulation, plan and result
handles. Frozen retains one baseline fitted policy at every outer point;
RetrainedBump fits at each outer point and differences the complete gradient
estimator, including the inner policy secant. E12 controls its inner relative
step, while J6 controls the outer absolute spot step. These estimate different
quantities and need not agree. The small path counts illustrate the API;
assess step bias, policy error and sampling dispersion separately.

Plans own their prepared contract/settings and history. Editing input cells
requires rebuilding the dependent handles. All dates here are after valuation;
same-day exercise is unsupported. See the [Excel contracts](../../docs/excel/README.md#native-lsmc-policy-curvature)
for policies, budgets, detached results and strict cell types.
