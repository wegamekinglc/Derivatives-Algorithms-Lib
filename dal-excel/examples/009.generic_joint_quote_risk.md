# Generic Joint Quote DV01 Worksheet Recipe

This recipe starts with three USD deposit calibration instruments in `B2:B4`,
two USD 3M swap calibration instruments in `C2:C3`, and typed IRS trade handles
in `B15:B16`. All use trade/start date `2025-01-02`; deposit maturities are
`2026-01-02`, `2027-01-02`, `2028-01-02`, with decimal quotes 0.020, 0.021,
0.022. Swap maturities are the first two dates, quotes 0.035 and 0.036. Use
ACT_365F conventions, a six-month fixed leg, and a three-month floating leg
projected from the forward slot. The existing `DEPOSIT.NEW`, `SWAP.NEW`, and
rate-trade constructors produce these handles.

| Cell/range | Value                                        |
|------------|----------------------------------------------|
| `D2:D4`    | 2025-07-02, 2026-07-02, 2027-07-02           |
| `E2:E3`    | 2025-07-02, 2026-07-02                       |
| `G2:H2`    | `parameterization`, `PIECEWISE_CONSTANT_FWD` |
| `G4:H4`    | `parameterization`, `PIECEWISE_LINEAR_FWD`   |
| `G5:H5`    | `baseLayeredOverDiscount`, TRUE              |
| `G7:H7`    | `tolerance`, 1e-11                           |
| `G8:H8`    | `initialGuess`, 0.025                        |
| `G9:H9`    | `maxEvaluations`, 1000                       |
| `G10:H10`  | `maxRestarts`, 100                           |
| `G12:H12`  | `jacobianMode`, `ANALYTIC`                   |
| `G13:H13`  | `computeEffJacobianInverse`, TRUE            |
| `M2:M3`    | `curve:0`, `curve:1`                         |
| `N2:N3`    | `discount`, `forward-3m`                     |

```text
J2: =JOINTCURVEDECLARATION.NEW("usd-ois",B2:B4,D2:D4,TRUE,"OIS","",G2:H2)
J3: =JOINTCURVEDECLARATION.NEW("usd-3m",C2:C3,E2:E3,FALSE,"OIS","3M",G4:H5)
J5: =JOINTMULTICURVECALIBRATIONSPEC.NEW(DATE(2025,1,2),"USD",J2:J3,G7:H10)
J7: =CALIBRATE.JOINTMULTICURVE(J5,G12:H13)
J9: =JOINTMULTICURVECALIBRATIONRESULT.GET.CURVE(J7,0)
J10: =JOINTMULTICURVECALIBRATIONRESULT.GET.CURVE(J7,1)
J12: =RATEPRICINGMARKET.NEW(DATE(2025,1,2),"USD",N2:N3,J9:J10)
J14: =JOINTMULTICURVEQUOTERISKPROVENANCE.NEW(J7,"usd-joint",M2:M3,N2:N3,J12)
J16: =RATEPORTFOLIOQUOTERISK.SPILL(B15:B16,J12,J14)
```

Trade handles must reference `discount` and `forward-3m` as their market
components and use the same valuation/fixing state. Supply the optional
fixing-snapshot handle to `RATEPRICINGMARKET.NEW` when historical observations
are required. Curve indices, ranges, and block ordinals are zero-based.

`JOINTMULTICURVECALIBRATIONRESULT.GET(J7,"effJacobianInverse")` returns the
full native-parameter by residual-quote matrix. Select `parameterRanges`,
`residualRanges`, or `residualInstrumentOrdinals` to inspect its axes. Scalar
selectors are `converged`, `solverEvaluations`, `jointMaxAbsResidual`,
`jointRmsResidual`, `effJacobianInverseScaling`,
`effJacobianInverseAvailability`, `effJacobianInverseMapping`, and
`jacobianModeUsed`; residual vectors are `marketRates`, `modelRates`, and
`residuals`, and the forward matrix selector is `jacobian`.

The inverse request defaults to false. For an underdetermined EXACT system,
enabling it chooses a fixed initial-Jacobian parameter subspace and can select
a different solution from the default solve. Preserve the same spec, guesses,
and inverse request for every quote-recalibration comparison. See the
[mapping and units contract](../../docs/methodology/generic_joint_quote_risk.md).

The spill retains the ten columns in the [quote-risk recipe](008.quote_risk.md),
including actual PV currency, price per decimal quote and price per +1 bp.
Use the dedicated joint provenance factory above. The legacy
`RATEQUOTERISKPROVENANCE.NEW` dispatcher retains its v1 generic-joint exclusion.
