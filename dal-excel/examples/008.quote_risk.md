## Quote-Space DV01 Worksheet Recipe

This recipe extends a worksheet that already contains one exact single-curve
calibration result, its bound rate-pricing market, and one or more typed rate
trade handles.

| Cell/range | Value |
|------------|-------|
| `B2` | exact single-curve calibration-result handle |
| `B3` | bound `RATEPRICINGMARKET.NEW` handle |
| `B4:B20` | rate-trade handles |
| `D2:D4` | the calibration's parameter-block keys |
| `E2:E4` | the corresponding market component keys |

Paste these formulas:

```text
G2: =SINGLECURVEQUOTERISKPROVENANCE.NEW(B2,"usd-ois",D2:D4,E2:E4,B3)
H2: =RATEPORTFOLIOQUOTERISK.SPILL(B4:B20,B3,G2)
```

`H2` spills ten columns in this order: `calibration`, `axis_fingerprint`,
`quote_key`, `quote_name`, `block`, `currency`, `quote_sensitivity`, `dv01`,
`availability`, and `reason`. Quote sensitivity is price per decimal quote and
DV01 is price per `+1 bp`. The currency column is the actual PV currency; rows
are not FX-converted.

For simultaneous XCCY or staged XCCY basis results, replace the provenance
constructor with `JOINTXCCYQUOTERISKPROVENANCE.NEW` or
`STAGEDXCCYBASISQUOTERISKPROVENANCE.NEW`, keeping the same five arguments.
