# Market F/D to local-volatility Monte Carlo

Load the DAL XLL in Windows Excel. Set evaluation date to 2026-11-16 (serial
46342) and spot to 100. Forwards use spot units; discounts are positive unitless
factors, volatility is decimal, and time is ACT/365 years. USD is the caller's
currency declaration. Use this headerless market table with actual Excel dates:

| Expiry     | Forward | Discount |
|------------|---------|----------|
| 2027-02-15 | 101     | 0.995    |
| 2027-05-17 | 99      | 1.005    |
| 2027-11-16 | 102     | 0.98     |

Use three headerless quote rows with columns
`id,expiry,strike,option_type,quote_type,mid,bid,ask,weight`.
Ids are `atm0` to `atm2`, expiry/strike match each market row's expiry/forward,
and the next fields are `CALL,DECIMAL_IV,0.20` followed by three empty cells.
Use vertical spot nodes `80,100,120`, time nodes `0.1,0.5,1.0`, and settings:

| Key      | Value |
|----------|-------|
| index    | EQ[A] |
| currency | USD   |
| factor   | W_EQ  |
| horizon  | 1.25  |

Name the input ranges and returned handle cells, then enter these formulas in
separate cells, leaving room below/right for spills:

```text
=INIT.GLOBALDATA(1)
=MARKETIVMARKET.NEW("market",evaluation_date,100,terms)
=MARKETIVFITREQUEST.NEW("request",market,quotes)
=MARKETIVFITRESULT.NEW("fit",request)
=MARKETIVFITRESULT.GET.SNAPSHOT(fit)
=MARKETIVDUPIREREQUEST.NEW("grid-request",spots,times)
=MARKETIVDUPIRERESULT.NEW("grid",snapshot,grid_request)
=MARKETIVLOCALVOLMODELSETTINGS.NEW("settings",settings_rows)
=MARKETIVLOCALVOLMODELDATA.NEW("model",grid,settings)
=MARKETIVLOCALVOLMODELDATA.GET.SUMMARY(model)
=MARKETIVLOCALVOLMODELDATA.GET.CARRY(model)
=MARKETIVLOCALVOLMODELDATA.GET.WARNINGS(model)
```

Create `SCRIPTVALUATIONSETTINGS.NEW` from a two-column range containing
`evaluation_date` and the same date serial; create `MONTECARLOSETTINGS.NEW`
from `method,mrg32`. Each product uses one date, 2027-11-16, and one event:
`pay PAYS 1`, `pay PAYS FIX(EQ[A])`, or
`pay PAYS MAX(FIX(EQ[A]) - 102, 0)`.
`PRODUCT.NEW(name,dates,events)` returns the product handle;
`MONTECARLO.VALUEWITHSETTINGS(product,model,16384,valuation,simulation)`
returns a `PV` table. DF must equal 0.98 within 2e-12; the forward claim targets
99.96 within 0.8; the call targets the independent Black value
`102*0.98*ERF(0.1/SQRT(2))` within 0.5. These are workflow smoke tolerances,
separate from numerical qualification and convergence studies.

`MARKETIVLOCALVOLMODELDATA.GET.EXECUTION(product,model,valuation,simulation)`
must show `prepared_columns=internal_steps` and `per_path_market_queries=0`.
`GET.CARRY` leaves the fractional-day horizon date blank. An AAD simulation
(`enable_aad,TRUE`) returns `DerivativeUnavailable`. Duplicate settings keys
return an error and preserve the earlier handle. Inspect fit/grid/model
diagnostics on failure; do not substitute a bare surface. The owning model
and typed settings have no archive/restore support.

Run the same recipe with explicit ranges and automatic guards from PowerShell:

```powershell
python dal-excel/tests/windows/run-market-iv-local-vol.py --xll C:/dal/build/dal-excel/dal_excel.xll --output worksheet.json
```

the loaded XLL hash/version/PID, and closes that workbook and process.
